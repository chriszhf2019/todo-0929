# 记言 Todo (VoxFlow)

将电话、短信和微信沟通整理为待办事项、双语通话纪要与 Obsidian Markdown 笔记的安卓风格应用。

Pixel 9 Pro Fold 的安装、授权和本地模型配置见：[PIXEL9PROFOLD.md](./PIXEL9PROFOLD.md)。

## 功能

- 电话、短信、微信信息录入与本地待办提取
- 安卓通知使用权接入：同步短信和微信通知正文
- 可选无障碍屏幕读取：读取前台聊天应用可见文字，节点读不到时用离线 OCR 兜底
- 应用使用监控与指令执行：记录前台应用、累计使用时长和最后可见文字，给出智能提示，并执行返回、桌面、滑动、点击或打开应用等系统操作
- 从待办直接唤起微信/QQ 并自动准备会话草稿，语音输入后自动执行多步指令
- 常驻桌面桌宠：屏幕角落常驻可拖动的猫猫，触发来电、聊天或通话结束时展开成提示卡片，通话结束后弹出摘要确认
- 安卓通话记录接入：同步来电、去电、未接和通话时长
- 通话录音文件导入、播放和转写文本整理
- 安卓系统语音识别、英文到中文翻译与行动项捕获
- 待办完成、删除、筛选、批量清理和来源定位
- Obsidian Markdown 预览、复制、下载与 `obsidian://` 深链
- 本地 Ollama 模型配置、联网状态检测与数据重置
- 浏览器离线提取、本地持久化、PWA 安装与离线缓存
- 应用回到前台时自动导入新通知和通话记录
- 待办编辑与 Android 本地到期提醒
- 完整数据备份导出与恢复

## 真实能力边界

普通安卓应用不能直接读取微信聊天数据库，也不能在未成为系统默认电话应用的情况下录制双方通话音频。当前应用采用系统允许的接入方式：

- 短信和微信通知内容来自用户主动授权的“通知使用权”，仅保存通知标题与正文；无障碍屏幕读取只读取当前前台可见文字。
- 通话记录同步联系人、号码、呼叫类型和通话时长，不包含通话录音。
- 英语翻译使用安卓系统语音识别服务，适用于免提通话或现场语音，不读取系统通话内部音频。
- `obsidian://` 深链和 Markdown 文件会通过系统应用打开并保存到 `Download/VoxFlow`。

## 应用监控与执行任务

进入“应用监控”页后：

1. 首次使用需要先在“系统设置”开启无障碍服务，系统会记录前台应用、事件次数、前台时长和最后一段可见文字。
2. 页面顶部“智能提示”会根据当前前台应用和最近记录给出跟进建议。
3. 可点击某个应用卡片上的“打开”直接唤起该应用，或使用“执行任务”输入框发出指令，例如“打开微信”“返回”“上滑”“点击 500 600”。
4. 指令可以用“然后”“接着”“；”串联成多步任务，并支持按界面文字点击、输入文字、等待和滚动查找，例如：`打开微信 然后 点击 搜索 然后 输入 张三`。
5. 点击麦克风按钮说出指令，识别后会先展示建议步骤，你确认后再执行，不需要再打字。

在“智能待办看板”中，每一条未完成待办右侧有“执行”按钮。点击后会打开执行面板，自动根据待办渠道生成建议步骤，例如微信待办会先打开微信、搜索联系人并填入待办内容。执行采用“建议、确认、执行”的逐步模式，每一步都由你确认后才操作；为避免误发消息，当前版本只准备到草稿，最终发送仍由你确认。

聚餐、聚会等餐饮类待办会额外询问人数、口味、预算和位置，并据此生成大众点评搜索计划。系统先打开搜索页并列出候选，选定具体餐厅后再继续进入详情或预订入口。

### 常驻桌宠与通话摘要

- 应用会把未完成待办同步到本机无障碍服务。屏幕角落常驻一个可拖动的小猫脸，平时待机，点击可回到记言 Todo。
- 当来电、打开微信 / QQ / 短信 / 电话，或通话结束时，桌宠会展开成提示卡片，显示关联待办数量；“查看”回到记言 Todo，“稍后”收起卡片。
- 普通电话结束后，应用会弹出“通话结束摘要”，显示联系人、通话时长和可编辑摘要；你可以勾选待办或手动补充，再选择加入待办。
- 普通安卓应用无法读取双方通话音频，因此摘要默认只包含系统通话记录，无法自动还原通话内容。

该能力参考 `jev-chat/jev-chat-jarvis` 的无障碍观测与动作执行思路，但只执行明确由用户发起的有限系统操作，且所有使用记录只保存在本机。

## 首次授权

打开应用后进入“系统设置”：

1. 点击“去授权通知使用权”，在系统列表中找到“记言 Todo 系统信息捕获”并开启。
2. 点击“申请麦克风权限”。
3. 点击“申请通话记录权限”。
4. 返回应用后点击“同步真实系统记录”。

## 运行

```bash
npm install
npm run dev
```

开发服务默认位于 `http://localhost:3000`。如端口被占用，可指定其他端口：

```bash
PORT=3010 npm run dev
```

## 生产构建

```bash
npm run lint
npm run build
NODE_ENV=production PORT=3010 npm start
```

构建结果位于 `dist/`，生产服务会同时提供前端静态资源和 API。

## Android APK

本机需安装 Android SDK、Build Tools 和 JDK 21（LiteRT-LM 端侧模型要求 Java 21）。执行：

```bash
npm run android:apk
```

生成的可安装调试包位于：

```text
dist/VoxFlow-Todo-1.3-release.apk
```

当前 APK 的包名为 `com.voxflow.todo`，最低支持 Android 7.0（API 24），目标版本为 Android 14（API 34）。应用内已包含离线提取、中文 OCR 与翻译降级逻辑，不依赖本地 Web 服务即可使用核心功能。

## Android 安装

可直接将 `dist/VoxFlow-Todo-1.3-release.apk` 传到 Android 设备安装，也可使用 Android Chrome 打开已部署的 HTTPS 地址后选择“安装应用”或“添加到主屏幕”。

## AI 配置

默认无需密钥即可使用共享的端侧规则引擎。如需启用 Gemini 云端增强，可参考 `.env.example` 配置 `GEMINI_API_KEY`。
